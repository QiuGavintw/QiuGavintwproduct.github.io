Bubble Sort｜氣泡排序法

氣泡排序會不斷比較相鄰的兩個數字：如果左邊比右邊大，就交換。大的數字就會慢慢往右移動，像泡泡一樣浮到最右邊。

💭 想像一群數字排隊，大的數字會一步一步「冒泡」到右邊。

演算法程式碼

for (let i = 0; i < n - 1; i++) {
// ① 每一輪確定一個最大值
  for (let j = 0; j < n - 1 - i; j++) {
// ② 掃描相鄰元素
    if (arr[j] > arr[j + 1]) {
// ③ 比較相鄰兩數
      swap(arr[j], arr[j + 1]);
// ④ 左大右小就交換
    }
  }
}
// ⑤ 排序完成

💡 學習重點

  • 比較相鄰元素
  • 大元素逐漸往右移動
  • 每輪會確定一個元素的位置

Selection Sort｜選擇排序法

選擇排序每一輪都從「還沒排好」的數字中找出最小值，再把它放到目前位置。前面排好的區域就會越變越長。

💭 每一輪都從剩下的數字中「挑出最小的」，放到正確位置。

演算法程式碼

for (let i = 0; i < n - 1; i++) {
// ① 每輪固定一個位置
  let minIdx = i;
// ② 假設目前位置就是最小值
  for (let j = i + 1; j < n; j++) {
// ③ 掃描剩餘資料
    if (arr[j] < arr[minIdx]) {
// ④ 找到更小的
      minIdx = j;
// ⑤ 更新最小值位置
    }
  }
  swap(arr[i], arr[minIdx]);
// ⑥ 交換到正確位置
}
// ⑦ 排序完成

💡 學習重點

  • 每輪尋找最小值
  • 找到後交換
  • 已排序區域逐漸增加

Insertion Sort｜插入排序法

插入排序把資料分成「左邊已排好」與「右邊還沒排」兩部分。每次從右邊拿出一個數字，像整理撲克牌一樣，插入到左邊正確的位置。

💭 就像整理撲克牌，一張一張拿起來，插到正確的位置。

演算法程式碼

for (let i = 1; i < n; i++) {
// ① 從第二個元素開始
  let key = arr[i];
// ② 取出目前元素（Key）
  let j = i - 1;
  while (j >= 0 && arr[j] > key) {
// ③ 向左比較
    arr[j + 1] = arr[j];
// ④ 較大的元素向右移動
    j--;
  }
  arr[j + 1] = key;
// ⑤ 插入正確位置
}
// ⑥ 排序完成

💡 學習重點

  • 維持左側已排序區域
  • 每次取出一個元素
  • 將元素插入正確位置
  • 很像整理撲克牌
