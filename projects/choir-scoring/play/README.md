# 🎵 合唱比賽計時計分系統

給音樂比賽現場工作人員使用的**計時＋評分工具**。同一畫面完成計時、隊伍管理、評分輸入、排名與匯出；不需要伺服器、不需安裝套件，直接用瀏覽器開啟即可。

---

## 使用方式

直接雙擊 `計時系統.html`（或拖曳進瀏覽器）。

### 計時

- **開始**：正數從 0 增加、倒數從設定時間減少，兩者同步。暫停後再按開始會從暫停位置繼續。
- **暫停**：兩者同時停在目前數值。
- **重置**：正數歸零、倒數恢復設定時間，並清除提醒。
- **時間設定**：1 秒～99 分鐘；計時進行中禁止修改。
- **提醒設定**：可開關提醒時間，必須小於比賽時間；提醒時倒數數字轉琥珀色並顯示「剩餘 X 分鐘」，10 秒後訊息消失，顏色維持到超時或重置。
- 倒數歸零後**不會停止**，會繼續顯示負數超時；正數超過設定時間轉紅。
- 快捷鍵：`Space` 開始／暫停、`R` 重置（輸入中或對話框開啟時不觸發）。

### 評分

評分分為**指定曲**與**自選曲**兩張卡片，細項、名稱與權重依 `評分表.xlsx`（分數尺度改為 0–100）：

| 卡片 | 細項 | 細項權重 | 卡片權重 |
| --- | --- | --- | --- |
| 指定曲 50% | 音準、節奏、音色 | 50% | 50% |
| 指定曲 50% | 團體創意 | 50% | 50% |
| 自選曲 50% | 音準、節奏、音色 | 40% | 50% |
| 自選曲 50% | 和聲 | 30% | 50% |
| 自選曲 50% | 指揮 | 30% | 50% |

- 每個細項由 **3 位評審**給分，範圍 **0–100 分**，輸入 step 為 0.5；三評審平均後加權。
- 總分公式：`(指定曲細項加權) × 0.5 + (自選曲細項加權) × 0.5 − 超時扣分`，滿分為 100。
- 分數草稿**依隊伍名稱分開保存**，切換隊伍不會互換；改名時草稿會跟著轉移。
- 指定曲卡片下方有獨立的 `最佳指揮獎` 勾選欄位，勾選狀態會隨分數草稿保存、寫入歷史紀錄並匯出；**不計入總分與排名**。
- 未填寫完整仍可儲存紀錄，但該筆不計總分與排名（會先詢問確認）。
- 即時試算會隨timer超時秒數更新超時扣分與總分。

### 統一設定

右上角只有一個「設定」按鈕，所有設定集中在同一個視窗：

| 區塊 | 內容 |
| --- | --- |
| 比賽時間 | 每隊 1 秒～99 分鐘 |
| 提醒 | 開關與提醒時間（需小於比賽時間） |
| 扣分與流程 | 每 x 秒扣 y 分、自動切換下一隊 |
| 外觀 | 深色／明亮模式 |
| 資料管理 | 清除所有分數草稿（需確認） |

- **超時扣分**：可設定「每 x 秒扣 y 分」，**未滿 x 秒仍以 x 秒計**。公式：`ceil(超時毫秒 / (x × 1000)) × y`（超時為 0 時不扣）。預設每 10 秒扣 1 分，y 可調 0–100。例如超時 32.45 秒、每 10 秒扣 1 分時扣 4 分。
- **自動切換下一隊**：勾選後，儲存紀錄會直接切到下一隊並重置計時；已是最後一隊則不切換。
- 計時進行中時「設定」按鈕會停用，避免更動比賽時間。

### 登記分數模式

- 右上角「登記分數模式」一鍵切換到**只保留評分登記**的畫面：隱藏計時器、出場順序、分頁與歷史紀錄，讓登記畫面更單純。
- 評分區上方有「目前隊伍」下拉選單，可直接切換要登記的班級；切換時會先保存當前草稿，且**不會重置計時器**。
- 模式下提供「儲存這隊分數草稿」與「儲存紀錄」兩個按鈕，功能與完整模式相同。
- 按「返回計時台」即可回到原畫面；模式存入 `localStorage`，重新整理後保留。

### 明亮模式

- 右上角「明亮模式／深色模式」按鈕可即時切換整套配色（只換色，不改排版）。
- 設定存入 `localStorage`，重新整理後保留；頁面载入時提前套用，不會閃一下深色。
- 切換不影響計時、分數草稿或歷史紀錄。

### 隊伍管理

- 班級名稱與出場順序依 `評分表.xlsx` 更新：一年5班(序號1)、一年3班(2)、一年信班(3)、一年仁班(4)、一年1班(5)、一年2班(6)、一年4班(7)、一年7班(8)、一年忠班(9)、一年6班(10)、一年孝班(11)。
- 右側依序號顯示所有隊伍，目前隊伍有底色與「目前」標籤，面板可獨立捲動。
- 點擊隊伍切換（需確認，且重置計時器）；`＋ 新增隊伍`、✎ 改名、✕ 刪除（需確認）、↑↓ 調整順序。
- 舊預設（A/B/C/D 或國字班名）在載入時會自動升級為新班名與順序；至少保留一個隊伍；順序與目前隊伍存入 `localStorage`。

### 歷史紀錄與排名

- 欄位：隊伍、正數時間、超過時間、超時扣分、總得分、排名、最佳指揮獎。
- 排名使用試算表 `RANK.EQ` 的競爭排名（同分並列，下一名跳號）。
- 歷史紀錄保留**儲存當下的隊伍名稱**，之後改名不影響舊紀錄。
- 清除歷史紀錄需先確認。

### 匯出

按右上角「匯出」可選擇：

| 格式 | 說明 |
| --- | --- |
| CSV | 含 UTF-8 BOM，Excel 直接開啟中文不亂碼；逗號／引號自動 escaping |
| Excel 相容 `.xls` | HTML 表格伪装成 `.xls`，保留完整欄位，可直接用 Excel 開啟 |
| 列印用 HTML | 新視窗開啟可列印頁面，可「列印／另存 PDF」 |

三種格式共用同一份歷史紀錄資料，含各評審平均、扣分、總分與排名。

## 資料儲存

使用 `localStorage`，重新整理後保留：

- `mcts.teams` / `mcts.currentTeam`：隊伍與順序／目前隊伍
- `mcts.duration` / `mcts.reminder` / `mcts.reminderEnabled`：時間與提醒
- `mcts.history`：歷史紀錄（含分數快照與排名）
- `mcts.scoreRules` / `mcts.scoreDrafts`：扣分規則與各隊分數草稿
- `mcts.theme`：明亮／深色模式
- `mcts.view`：完整模式／登記分數模式

進行中的計時**不會恢復**，載入後一律為未開始狀態。

## 檔案架構

| 檔案 | 職責 |
| --- | --- |
| `計時系統.html` | 主要入口（新配置：頂列＋計時舞台＋隊伍側欄＋三分頁） |
| `style.css` | 深色控制室視覺、大型計時數字、狀態色彩、響應式 |
| `js/storage.js` | `AppStorage`：localStorage 讀寫 |
| `js/timer.js` | `TimerEngine`：以 `performance.now()` 計算，避免累加誤差 |
| `js/teams.js` | `TeamManager`：隊伍、順序、目前隊伍 |
| `js/scoring.js` | `ScoreManager`：評分欄位定義、加權試算、扣分、草稿與規則 |
| `js/history.js` | `HistoryManager`：紀錄、競爭排名 |
| `js/ui.js` | `UI`：對話框與 Toast |
| `js/export.js` | `ExportManager`：CSV / XLS / 列印 HTML |
| `js/app.js` | 主程式：UI 串接、渲染迴圈、快捷鍵、分頁、匯出 |
| `tests/` | 瀏覽器測試頁與 Node.js 執行器 |
| `v0.html` | 設計稿 v0（配置與設計 token 參考，可保留） |

## 測試方式

### Node.js

```text
node tests/run.js
```

目前輸出：`Tests: 45 PASS / 0 FAIL`。

### 瀏覽器

開啟 `tests/index.html`，會自動執行並顯示 PASS／FAIL。測試會清空 `localStorage` 中的練習資料。

### 涵蓋情境

計時開始／暫停／繼續／重置／負數超時、提醒觸發與開關、隊伍增刪改與排序（含舊班名升級）、歷史紀錄與名稱快照、localStorage 往返（含主題與登記模式）、評分加權公式、超時扣分向上取整、草稿轉移、最佳指揮獎欄位、競爭排名、三種匯出格式。

## 設計依據

畫面重作參考了以下設計 skill 的指引：`frontend-design`、`web-design-engineer`、`ui-ux-pro-max`、`web-artifacts-builder`。

- 模式：Redesign · Preserve（保留既有行為與資料，重排畫面）
- 視覺：舞台控制室 — 深墨藍底 `#12171B`、面板 `#1B232A`、琥珀色 `#E8A33D` 為唯一強調色、超時紅 `#E05252`
- 字型：標題與計時用襯線字（`Noto Serif TC` / `Songti TC`），內文用無襯線；計時數字 `tabular-nums`
- 遵守無障礙對比、44px 以上触碰目標、鍵盤焦點可見、`prefers-reduced-motion`
- 刻意避開制式化 AI 視覺：紫色漸層、統一圓角卡片、emoji 當圖示、Inter 字型
