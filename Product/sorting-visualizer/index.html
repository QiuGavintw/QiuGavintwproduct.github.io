Bubble Sort｜氣泡排序法

比較相鄰的兩個數字，左邊比較大就交換——大的數字會像泡泡一樣，慢慢往右移動。

演算法程式碼

for (let i = 0; i < n - 1; i++) {
// ① 每一輪確定一個最大值
  for (let j = 0; j < n - 1 - i; j++) {
// ② 掃描相鄰元素
    if (arr[j] > arr[j + 1]) {
// ③ 比較相鄰兩數
      swap(arr[j], arr[j + 1]);
// ④ 左大右小就交換
    }
  }
}
// ⑤ 排序完成

💡 學習重點

  • 比較相鄰元素
  • 大元素逐漸往右移動
  • 每輪會確定一個元素的位置

Selection Sort｜選擇排序法

每一輪從還沒排好的數字中找出最小值，把它放到正確的位置。

本排序法特殊狀態：最小值

演算法程式碼

for (let i = 0; i < n - 1; i++) {
// ① 每輪固定一個位置
  let minIdx = i;
// ② 假設目前位置就是最小值
  for (let j = i + 1; j < n; j++) {
// ③ 掃描剩餘資料
    if (arr[j] < arr[minIdx]) {
// ④ 找到更小的
      minIdx = j;
// ⑤ 更新最小值位置
    }
  }
  swap(arr[i], arr[minIdx]);
// ⑥ 交換到正確位置
}
// ⑦ 排序完成

💡 學習重點

  • 每輪尋找最小值
  • 找到後交換
  • 已排序區域逐漸增加

Insertion Sort｜插入排序法

把新的數字插入已經排好的區域，就像整理撲克牌一樣放進正確位置。

本排序法特殊狀態：Key（要插入的數字）

演算法程式碼

for (let i = 1; i < n; i++) {
// ① 從第二個元素開始
  let key = arr[i];
// ② 取出目前元素（Key）
  let j = i - 1;
  while (j >= 0 && arr[j] > key) {
// ③ 向左比較
    arr[j + 1] = arr[j];
// ④ 較大的元素向右移動
    j--;
  }
  arr[j + 1] = key;
// ⑤ 插入正確位置
}
// ⑥ 排序完成

💡 學習重點

  • 維持左側已排序區域
  • 每次取出一個元素
  • 將元素插入正確位置
  • 很像整理撲克牌

三種排序法比較

以下複雜度是針對常見實作與條件的教學簡化表示，重點是理解三種演算法的差異。

排序法核心概念最佳時間平均時間最差時間
氣泡排序相鄰比較與交換O(n)O(n²)O(n²)
選擇排序找出最小值O(n²)O(n²)O(n²)
插入排序插入正確位置O(n)O(n²)O(n²)

💡 為什麼？

O(n)：資料增加一倍，大約就多做一倍的事情。

O(n²)：資料增加一倍，工作量可能增加到約四倍。

10 個資料 → 約 100 次工作　｜　100 個資料 → 約 10,000 次工作

記憶小技巧：三種演算法都是「比較型」排序，平均時間複雜度都是 O(n²)；若資料「接近排序完成」，氣泡排序與插入排序可以做到最佳時間 O(n)。
