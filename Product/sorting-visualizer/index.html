比較相鄰的兩個數字，左邊比較大就交換——大的數字會像泡泡一樣，慢慢往右移動。

演算法程式碼

for (let i = 0; i < n - 1; i++) {
// ① 每一輪確定一個最大值
  for (let j = 0; j < n - 1 - i; j++) {
// ② 掃描相鄰元素
    if (arr[j] > arr[j + 1]) {
// ③ 比較相鄰兩數
      swap(arr[j], arr[j + 1]);
// ④ 左大右小就交換
    }
  }
}
// ⑤ 排序完成

  • 大元素逐漸往右移動
  • 每輪會確定一個元素的位置

演算法程式碼

for (let i = 0; i < n - 1; i++) {
// ① 每輪固定一個位置
  let minIdx = i;
// ② 假設目前位置就是最小值
  for (let j = i + 1; j < n; j++) {
// ③ 掃描剩餘資料
    if (arr[j] < arr[minIdx]) {
// ④ 找到更小的
      minIdx = j;
// ⑤ 更新最小值位置
    }
  }
  swap(arr[i], arr[minIdx]);
// ⑥ 交換到正確位置
}
// ⑦ 排序完成

💡 學習重點

  • 每輪尋找最小值
  • 找到後交換
  • 已排序區域逐漸增加

演算法程式碼

for (let i = 1; i < n; i++) {
// ① 從第二個元素開始
  let key = arr[i];
// ② 取出目前元素（Key）
  let j = i - 1;
  while (j >= 0 && arr[j] > key) {
// ③ 向左比較
    arr[j + 1] = arr[j];
// ④ 較大的元素向右移動
    j--;
  }
  arr[j + 1] = key;
// ⑤ 插入正確位置
}
// ⑥ 排序完成

💡 學習重點

  • 維持左側已排序區域
  • 每次取出一個元素
  • 將元素插入正確位置
  • 很像整理撲克牌

演算法程式碼

let sortedResult = [];
// 排序結果
for (let i = 0; i < n; i++) {
// ① 每一輪挑一個
  let best = 剩餘資料[0];
// ② 先假設第一筆最好
  for (let j = 1; j < 剩餘長度; j++) {
// ③ 掃描剩餘資料
    if (剩餘資料[j] < best) {
// ④ 找到「目前看起來更好」的
      best = 剩餘資料[j];
// ⑤ 更新目前最佳選擇
    }
  }
  sortedResult.push(best);
// ⑥ 貪心選擇：排進結果

💡 Greedy 是什麼？

  • 「每一步先做出目前看起來最好的選擇。」
  • 不必回頭考慮所有組合，只看當下最有利的選項
  • 提醒：貪心法不代表每一個問題都能得到全域最佳答案
  • 這個示範只是把「每次挑最小」延伸成一個教學型排序法

五種演算法比較

以下複雜度是針對常見實作與條件的教學簡化表示，重點是理解五種演算法的差異。Greedy Sort 的數值依本教學示範的實作計算。

排序法核心概念最佳時間平均時間最差時間
氣泡排序相鄰比較與交換O(n)O(n²)O(n²)
選擇排序找出最小值O(n²)O(n²)O(n²)
插入排序插入正確位置O(n)O(n²)O(n²)
合併排序拆分後合併O(n log n)O(n log n)O(n log n)
貪心排序每次挑目前最好O(n²)O(n²)O(n²)

💡 為什麼？

O(n)：資料增加一倍，大約就多做一倍的事情。

O(n²)：資料增加一倍，工作量可能增加到約四倍。

10 個資料 → 約 100 次工作　｜　100 個資料 → 約 10,000 次工作

合併排序　O(n log n)：先把資料一直切半，所以會有大約 log₂(n) 層；每一層都要處理 n 個資料，因此是 O(n log n)。

8 個資料 → 3 層（8→4→2→1）｜100 個資料 → 約 7 層，每層都處理全部資料

貪心排序　O(n²)：依本示範的實作，每一輪都要把「剩下還沒排」的資料從頭到尾掃一遍找最小的：第一次看 n 個、第二次看 n−1 個、第三次看 n−2 個…全部加起來大約 n(n−1)/2，所以資料變兩倍，工作量變約四倍。

10 個資料 → 約 45 次比較　｜　100 個資料 → 約 4,950 次比較

記憶小技巧：比較型排序中，氣泡、選擇、插入、貪心平均都是 O(n²)；若資料「接近排序完成」，氣泡與插入可做到最佳 O(n)。合併排序不管資料怎麼排都是 O(n log n)，缺點是通常需要額外的暫存空間。

空間：氣泡、選擇、插入、貪心（本示範實作）通常額外空間 O(1)；合併排序需要暫存左右兩半，額外空間 O(n)。
