# Qiu Gavin 作品集知識庫

本知識庫以 [Open Knowledge Format (OKF) v0.2](https://github.com/GoogleCloudPlatform/open-knowledge-format) 整理作品集全部專案，含技術說明、功能亮點與連結。

## 專案

* [澎湖頭足探險](projects/cephalopod.md) - 澎湖真實頭足類互動教育遊戲（16 物種、海洋圖鑑、保育知識）
* [打字訓練中心](projects/typing-practice.md) - 國高中生英文打字訓練 Web App（課程、遊戲化、錯誤分析）
* [搜尋演算法視覺化](projects/search-visualizer.md) - 順序搜尋與二分搜尋動畫視覺化工具
* [排序演算法視覺化](projects/sorting-visualizer.md) - 氣泡、選擇、插入、合併、貪心五種排序動畫
* [挖金礦 Gold Miner](projects/gold-miner.md) - 經典鉤爪挖掘小遊戲（10 關卡、商店升級、音效粒子）
* [午餐小天使](projects/lunch-angel.md) - 高中生校園午餐 LINE 聊天機器人（Node.js 後端）
* [台灣麻將](projects/mahjong.md) - 四人台灣 16 張麻將單機遊戲（AI 玩家、完整規則、Canvas 牌桌）
* [二元樹視覺化](projects/binary-tree.md) - 互動式 BST 教學工具（插入、搜尋、刪除、四種走訪動畫）
* [高一合唱・評分計時台](projects/choir-scoring.md) - 合唱比賽計時與評分工具（三評審加權、超時扣分、排名與匯出）
